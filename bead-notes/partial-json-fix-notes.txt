## Completed bead contextio-8ruy: Handle partial JSON objects across chunks in SSE streaming

### Solution Summary

Fixed SSE streaming JSON processing to handle partial JSON objects that span chunk boundaries. The issue was that when a JSON object was split across multiple network chunks, the parser would try to parse incomplete JSON, causing errors.

### Key Changes Made

1. **Buffer Implementation**: Added a `jsonBuffer` variable to accumulate partial JSON across chunks
2. **Smart Chunk Processing**: Prepend leftover partial JSON to incoming chunks before processing
3. **Complete Object Detection**: Only process JSON objects that end with `}` character
4. **Incomplete Object Handling**: Save incomplete trailing parts for the next chunk instead of processing them

### Technical Details

- **File Modified**: `packages/proxy/src/forward.ts` (lines ~516-570)
- **Buffer Logic**: 
  - Accumulate partial JSON in `jsonBuffer`
  - Prepend to current chunk: `const fullText = jsonBuffer ? jsonBuffer + text : text`
  - Split complete objects: `/(?<=})\s*(?={)/`
  - Save incomplete trailing parts for next chunk
- **Edge Cases Handled**:
  - Empty chunks
  - Malformed JSON boundaries
  - Multiple JSON objects in single chunk
  - Chunk boundaries in the middle of JSON strings/objects
